Instrument Lab. Select a standard instrument to see its full composition — every partial's frequency ratio and amplitude, plus envelope, inharmonicity, vibrato, and breath — and edit any value. Click the keyboard to hear your changes instantly. Save keeps your version as a new custom instrument (browser storage always; also written to a connected folder if you've set one up). Custom instruments reappear automatically next time you open this page. Note: real folder sync uses the File System Access API, supported in Chromium browsers (Chrome, Edge) but not Firefox or Safari — use Export/Import there instead.
